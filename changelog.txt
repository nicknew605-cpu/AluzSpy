Change log from 1.2.1 Stable to 1.2.1 Max:

Fixes:

dump2 no longer overwrites `CFG.decode` and `CFG.sandbox` on every start; your saved values are kept.

deep no longer resets every module to "enabled" when the version changes. A new config migrator only adds missing keys and keeps your choices. `CFG.nc` is no longer forced on.

decode: `F.api` is merged instead of replaced, so the load order cannot drop commands any more.

decode: the variable renamer skips property names (`a.b`, `a:b`) and table keys, and skips names that also appear as strings.

decode: sandbox with `net` now allows at most 3 fetches per run, 512 KB each, and refuses local and private hosts.

runtime: `reload()` now points to `loader.lua`, and the frame budget follows the queue load.

New modules:

deobfuscate: constant string and number folding, `string.rep/reverse/sub/char`, `table.concat` and `bit32` folding, `a["b"]` to `a.b`, string table restoration, dead branch removal, literal comparison folding, scope-aware renaming and `loadstring` layer extraction. Every pass is checked and rolled back on failure. VM and dispatch structures are flagged in the report. Output goes to `*.deobf.lua`. Turn on automatic mode with `AluzSpy.set("autoDeobf", true)`.

reverse: closure, constant, upvalue and prototype scan, remote to script links with confidence and evidence, callgraph, optional deep GC scan, and `AluzSpy.reverse()` plus `AluzSpy.reverseFind(text)`. The scan is limited by time and object count.

vip: profiles (`lite`, `standard`, `max`, `safe`), one-click scan, report, redact and safe mode through `AluzSpy.vip(...)`.

watch is now part of the load order. It provides the masking and schema helpers that save depends on. The `ps` and `tc` hooks stay off unless you enable them.

Core:

Observer pipeline `F.on(kind, name, fn, prio)` for modules that only need to watch events.

Module registry and `AluzSpy.modules()`. Stages report their state and retry twice after an error.

Job queue: priorities, timeouts, pause and cancel.

Adaptive frame budget.

Dump:

Priority script queue: scripts that call remotes first, then the rest. The scan limit of 400 is kept, with a reserve for priority scripts.

Decompile failures are recorded with a reason (timeout, error, empty, bad output).

Hooks and health:

Per-hook reinstall limits with backoff, plus conflict detection for `__namecall`.

AI:

`AluzSpy.protect(name)` keeps a remote from being quieted, and `AluzSpy.threshold(name, mult)` raises its thresholds.

Save and UI:

Session schema 6: `modules`, `deobf`, `reverse`, `vip`, `dumpfail` and `redaction`. Reports are redacted by default (`CFG.redact`). Set `CFG.redactIds` to also mask your player name and UserId.

The counter shows `+` in the max profile, and the stats popup shows the profile and module count.

Loader:

Module manifest at `getgenv().AluzSpyManifest`, version guard, `getgenv().AluzSpyRef` to pin a branch, tag or commit, `getgenv().AluzSpyDisable` to skip optional modules, and a cache file per version.

Loading order (src/): core, core2, dump, decode, dump2, deobfuscate, hooks, hooks2, deep, health, actor, ai, chain, watch, analysis, reverse, hybrid, vip, save, ui, runtime.

Retain: hooks2, actor, chain (only the version marker line was added).

Replace: core, core2, dump, decode, dump2, hooks, deep, health, ai, analysis, hybrid, watch, save, ui, runtime, loader.

Create new: deobfuscate, reverse, vip.

Change log from 1.2 Max (1.2.1 Beta) to 1.2.1 Stable:

Menu: now simplified to just [ - ] [counter] [SAVE]; more compact than the previous version.

Removed the NC button and chip panel.

All modules activate automatically; the first run of this version resets all configurations to "enabled."

Consolidated: clicking SAVE generates a `Session_<place>_<time>.txt` file with clearly organized sections (loader, UI lib, main script, game, bytecode, encrypted payload, critical remote calls, diff).

Dumps are kept in RAM, eliminating the clutter of 30–40 separate files.

To split files as before, call `AluzSpy.split(true)`.

Crash protection: each dump is temporarily written to `AluzSpy/.spool`.

If this file remains upon the next launch, the tool automatically consolidates it into `Recovered_*.txt`.

Deep Dump: detects Luarmor, Luraph, MoonSec, IronBrew, etc., and activates a 60-second deep-scan mode. The tool retains the encrypted payload and performs a secondary scan.

`loadstring` operations log execution results and new global variables.

Stage tracking: visualizes the loading chain (loader → HttpGet → loadstring → ...) with status indicators (dumped vs. missing).

Missing payload: provides alerts—e.g., "loaded but not executed," "loader VM lacks internal payload," or "UI lib present but feature code missing"—along with suggested next steps.

Smart deduplication: recognizes versions differing only by key or HWID. Detects changes in URLs or `script_id` between runs and automatically generates a diff that includes structural changes.

Hybrid dump: for scripts invoking remote calls, both source code and bytecode are saved and linked together.

Improved obfuscator identification with detailed reasoning. Risk factors clearly explained: heavy VM usage, anti-tamper mechanisms, constant encryption, control-flow obfuscation, etc. Continuous hook health monitoring: test each hook every 20 seconds, auto-reinstall, and auto-reactivate temporarily interrupted hooks. The actor hook automatically detects duplicate logs and stops further injection.
