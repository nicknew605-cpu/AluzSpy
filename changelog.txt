AluzSpy 1.2.2 Beta
==================

Upgrade path: 1.2.1 Max -> 1.2.2 Beta

CRITICAL FIXES
--------------
* hooks2: no longer installs a second __namecall on top of hooks.lua.
  Double namecall + s2c was the main crash when hx and s2c were both on.
  hx now chains into F.ncHook when nc is already installed.
* hooks2: fixed incomplete NETM table (was only { Http }).
* save.lua: was corrupted on the public repo (duplicate of health.lua).
  Fully rewritten — SAVE button, AluzSpy.save(), session JSON+TXT all work again.

DUMP (stronger)
---------------
* More obfuscator fingerprints: Luarmor, Hercules, AstroProtect, PSU, Fluxus, VM, Bytecode, LPH_ variants.
* Lower body accept threshold (16 bytes) so short loaders are still captured.
* Capacity raised: DUMP_MAX 500, DUMP_FILE_MAX 12MB, DUMP_TOTAL ~96MB, LOGCAP 2500, ATT_CAP 500.
* dumpmax: spill earlier (75% mem / 14MB store), more files per spill (40), faster interval (3s).
* deep mode window 90s (was 60s), secondary GC/script scan at 15s.

DEOBFUSCATE
-----------
* autoDeobf defaults to true in beta (still overridable).
* dumpmax auto-queues every non-binary dump into the deobf pipeline when autoDeobf is on.

HOOKS
-----
* hx + s2c + ac can all be on at the same time without the previous crash path.
* Default mods: req enabled, profile default "max", decode/net/autoDeobf/autoReverse on.
* Schema bumped to 4 so old configs migrate cleanly.

VIP max profile
---------------
* net = true, dumpSpill = true, deob = true in addition to previous max flags.
* scan() still runs: dump -> decode -> deobfAll -> reverse.

SAVE
----
* Session writes Save_<place>_<time>.json (meta + dump index + log tail)
  and matching .txt human report (summary, chain, missing/advice, modules, remotes).
* Integrates deobf report, reverse summary, vip status, health.

VERSION
-------
* All modules stamped aluzspy@1.2.2-beta / VERSION = "1.2.2-beta".
* Cache file: AluzSpy/bundle_1.2.2-beta.lua

Commands unchanged; prefer:
  AluzSpy.vip("profile", "max")
  AluzSpy.vip("scan")
  AluzSpy.save()
